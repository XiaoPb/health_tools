# Check 场景正则分类设计

## 目标

为 `check` 增加 `--scene-regex` 参数，按文件相对路径提取场景分类。正则必须包含命名捕获组 `(?P<scene>...)`；匹配成功时使用该捕获组内容，未匹配或未提供参数时使用 `default`。

## 数据流

CLI 将正则传入 `CheckRequest` 和 `run_check`。运行普通检查时，以输入根目录为基准计算每个文件的相对路径，执行正则搜索并把场景保存到 `FileCheckReport`。主检查报告、精简报告及分拣生成的 normal/abnormal 文件清单都增加 `场景分类` 列。

## 校验与兼容性

正则语法错误或缺少 `scene` 命名组时返回请求校验错误。未指定参数时不改变检查逻辑，报告场景统一为 `default`。已有报告在 `--sort` 模式缺少场景列时按 `default` 兼容处理。

## 测试

覆盖命名组匹配、未匹配/未指定的 default、非法正则、缺少命名组，以及主报告和精简报告的场景列；验证旧报告分拣仍可工作。
