# PSD Comp 折线与动态标题留白设计

## 目标

在离线结果 PSD 图片的 PPG 子图中增加 comp 心率折线，并在顶部出现第三行
`Comp vs Polar` 指标时增加标题区留白，避免指标文字挤压或遮挡 PPG 子图标题。

## Comp 折线

PSD 绘图继续使用共用 VSHB 读取器提供的 `comp` 标准列。单个 VSHB 文件的 comp 至少
包含一个大于 0 的数值时，视为有效并绘制折线；comp 全为 0、全为空值或列缺失时跳过。

comp 折线采用亮青色 `#00E5FF`、虚线 `--`、线宽 `2`。该颜色和线型是根据 Viridis PSD
背景与现有黑色 offline、白色 online、红色 polar 折线的并列效果选定。comp 在线条绘制
顺序中位于 polar 之后，使它在曲线重合时仍易于识别。

comp 折线是否绘制不依赖 polar。polar 无有效值但 comp 有效时仍绘制 comp；此时顶部
准确度仍按现有规则只显示 `Online vs Offline`，因为 comp 缺少指定参考值。

## 动态图例

PPG 子图不再为两种 polar 状态分别写死图例。绘制每条折线时同步追加图例标签，最终按
以下固定顺序显示实际存在的曲线：

1. `pred(offline)`
2. `mcu(online)`
3. `polar(ref)`
4. `comp`

因此 comp 无效时不会留下空图例项，polar 无效而 comp 有效时图例仍能正确显示三条曲线。

## 动态标题留白

绘图前先生成顶部准确度文字行，再把实际行数传给子图顶部位置计算。无 overlay 时保持
`top=0.88`。有 overlay 时沿用现有基础值：四子图 axis 模式为 `0.88`，两子图 rms 模式为
`0.80`。

当准确度文字达到三行，即出现 `Comp vs Polar` 时，在基础值上减去 `0.04`：

- axis 四子图模式使用 `top=0.84`。
- rms 两子图模式使用 `top=0.76`。

一行或两行指标仍使用原有顶部位置，避免没有 comp 的图片产生多余空白。图片整体尺寸和
每种模式的子图数量保持不变。

## 文档与测试

更新 `docs/cmd_plot.md` 和 `docs/cmd_offline.md`，说明 comp 折线的有效条件、颜色、线型、
条件图例和动态留白。同步更新架构文档对 VSHB overlay 的描述。

测试覆盖：

- comp 有效时绘制 `#00E5FF`、`--`、线宽 2 的折线。
- comp 全为 0 或缺失时不绘制 comp，也不增加图例项。
- polar 缺失而 comp 有效时仍绘制 comp，并生成正确图例顺序。
- 一至两行指标保持原顶部位置，三行指标分别使用 axis `0.84` 和 rms `0.76`。
- 生成代表性 axis 与 rms 图片，检查图片非空，并人工核对标题文字、图例和 PPG 子图没有
  重叠。
